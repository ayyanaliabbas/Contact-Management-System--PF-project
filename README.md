# Contact Management System

A console-based Contact Management System developed in C++ as a semester project.
## Features

- Add new contacts
- View all contacts
- Search contacts by name
- Edit existing contacts
- Delete contacts
- Email validation
- Duplicate contact checking
- Save contacts using file handling
- Load saved contacts when the program starts

## Technologies Used

- C++
- Structures
- Arrays
- Functions
- File Handling

## Project Files

- `Project.cpp` — Main C++ source code
- `record.txt` — Stores contact records

## How to Run

1. Download or clone this repository.
2. Open `Project.cpp` in any C++ IDE.
3. Compile and run the program.
